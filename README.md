# Mod Scanner Tool for Lobotomy Corporation

扫描《脑叶公司》(Lobotomy Corporation) Mod 文件并整理信息的工具集。

## 功能

- 递归搜索 Mod 文件夹中的 Equipment ID
- 提取 EGO 饰品、武器、护甲数据
- 输出为可读的文本格式

## 运行环境
- Python 版本 >= 3.6

## 使用方法

1. 复制 `config.json.example` 为 `config.json`
2. 编辑 `config.json`，设置你的 Mod 搜索目录
3. 运行任意脚本，例如：
   ```bash
   python "1A-1-递归搜索-EquipmentID.py"
   ```
